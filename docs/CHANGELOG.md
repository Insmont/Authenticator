# 变更日志 (Changelog)

## v2026.0.0

这是 Authenticator 的第一个正式版本！本应用旨在为您提供安全、开源且现代化的双重身份验证（2FA）体验。

### 核心功能

- **OTP 令牌管理**：支持 TOTP 和 HOTP 算法，为您的各类账户提供动态验证码。
- **多种添加方式**：支持通过扫描二维码（QR Code）快速添加账户，或手动输入密钥。
- **全方位安全保障**：
  - **生物识别锁定**：支持指纹或面部识别，防止未授权访问。
  - **强加密存储**：使用 Android KeyStore 和 EncryptedDataStore 保护您的账户密钥。
  - **隐私模式**：支持在最近任务中隐藏界面快照。
  - **Root 环境检测**：提醒用户设备安全状态，防止敏感数据在不安全环境下泄露。
- **备份与恢复**：支持加密导出备份文件，方便您在更换设备时安全迁移数据。
